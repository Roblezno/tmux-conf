# Tmux config

Personal tmux configuration based on [Oh My Tmux][oh-my-tmux], with a
Solarized Osaka theme matching Neovim, sensible navigation bindings, Wayland
clipboard integration, mouse support, and the [tmux-menus][tmux-menus] plugin.

## Features

- Oh My Tmux tracked as a pinned Git submodule.
- Portable XDG layout under `~/.config/tmux`.
- Solarized Osaka (vivid) colour palette and status line.
- `Ctrl-b` as the primary prefix and `Ctrl-a` as a secondary prefix.
- Windows and panes numbered from 1.
- New panes retain the current working directory.
- Mouse mode enabled by default and toggleable at runtime.
- Copy-mode selections copied to the OS clipboard through `wl-copy` on
  Wayland.
- TPM-managed [tmux-menus][tmux-menus] plugin.
- Generated plugins and logs excluded from Git.

## Repository layout

```text
~/.config/tmux/
├── .gitmodules
├── oh-my-tmux/       # pinned upstream Git submodule
├── plugins/          # generated by TPM; ignored by Git
├── tmux.conf         # symlink to oh-my-tmux/.tmux.conf
└── tmux.conf.local   # personal settings tracked by this repository
```

Do not edit `tmux.conf` or files inside `oh-my-tmux`. Put personal changes in
`tmux.conf.local`.

## Requirements

- tmux 2.6 or newer
- Git
- `awk`, `perl`, `grep`, and `sed`
- A terminal that exports `TERM=xterm-256color`
- `wl-copy` from `wl-clipboard` for Wayland clipboard integration
- A UTF-8 locale

Recommended extras are Neovim and a Nerd Font or Powerline-compatible font.
On Arch Linux and derivatives:

```sh
sudo pacman -S tmux git wl-clipboard neovim
```

## Fresh installation

Back up an existing tmux configuration before installing. Then clone this
repository and its Oh My Tmux submodule:

```sh
git clone --recurse-submodules \
  https://github.com/Roblezno/tmux-conf.git \
  ~/.config/tmux
tmux
```

On first launch, Oh My Tmux automatically installs TPM and the configured
plugins into `~/.config/tmux/plugins/`. If automatic installation has not
finished, press `<prefix> I` inside tmux.

### Clone made without submodules

```sh
git -C ~/.config/tmux submodule update --init --recursive
```

### Configure the editor

Oh My Tmux uses `$VISUAL`, then `$EDITOR`, for `<prefix> e`. For fish:

```fish
set -Ux EDITOR nvim
set -Ux VISUAL nvim
```

For POSIX-compatible shells, add the following to the relevant shell startup
file:

```sh
export EDITOR=nvim
export VISUAL=nvim
```

## Everyday usage

`<prefix>` means either `Ctrl-b` or `Ctrl-a`.

| Binding | Action |
| --- | --- |
| `<prefix> e` | Edit `tmux.conf.local` |
| `<prefix> r` | Reload the configuration |
| `<prefix> \` | Open tmux-menus |
| `<prefix> m` | Toggle mouse mode |
| `<prefix> -` | Split into top and bottom panes |
| `<prefix> _` | Split into left and right panes |
| `<prefix> h/j/k/l` | Move between panes |
| `<prefix> H/J/K/L` | Resize panes |
| `<prefix> C-h/C-l` | Move between windows |
| `<prefix> Enter` | Enter copy mode |
| `<prefix> I` | Install missing TPM plugins |
| `<prefix> u` | Update TPM plugins |

Mouse mode starts enabled. `<prefix> m` changes it for the current tmux server.
Copying a selection in copy mode also sends it to the Wayland clipboard.

## Customization

Edit `tmux.conf.local`, then press `<prefix> r`:

```sh
nvim ~/.config/tmux/tmux.conf.local
```

Important local settings include:

```tmux
set -g mouse on
tmux_conf_copy_to_os_clipboard=true
set -g @plugin 'jaclu/tmux-menus'
```

The colour variables near the top of `tmux.conf.local` define the Solarized
Osaka (vivid) theme, taken from solarized-osaka.nvim. Powerline separators are
available but currently disabled.

## Updating

Update this repository and its pinned submodule:

```sh
git -C ~/.config/tmux pull --ff-only
git -C ~/.config/tmux submodule update --init --recursive
```

To intentionally update Oh My Tmux to its latest upstream revision:

```sh
git -C ~/.config/tmux/oh-my-tmux pull --ff-only
git -C ~/.config/tmux add oh-my-tmux
git -C ~/.config/tmux commit -m "chore: update Oh My Tmux"
```

TPM plugins update automatically with the current configuration. They can also
be updated manually with `<prefix> u`.

## Troubleshooting

Check that the main config symlink and submodule resolve:

```sh
readlink -f ~/.config/tmux/tmux.conf
git -C ~/.config/tmux submodule status
```

Inspect tmux paths and recent messages from inside a session:

```sh
tmux show-environment -g TMUX_CONF
tmux show-environment -g TMUX_PLUGIN_MANAGER_PATH
tmux show-messages
```

Test tmux without any configuration:

```sh
tmux -L clean-test -f /dev/null
```

If configuration changes do not appear, reload with `<prefix> r`. After a tmux
upgrade, fully restart the server only after saving or closing important
sessions:

```sh
tmux kill-server
```

`tmux-menus` has a known left-arrow navigation issue on tmux 3.7c. Select the
Back entry and press Enter instead; the issue is fixed in tmux 3.8.
